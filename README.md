# Домашнее задание 9 — Оптимизация производительности фронтенда

Репозиторий содержит текстовый отчёт для темы 11 дисциплины «Разработка прототипов программных решений».

## Файлы

- `performance-audit-report.md` — готовый отчёт по заданиям 1–4: аудит Lighthouse, анализ Performance, рекомендации и краткая оптимизация рендеринга.
- `optimized-demo.html` — демонстрационная реализация одной оптимизации из задания 4: предзагрузка LCP-изображения, размеры изображений, lazy loading, критический CSS и отложенный JavaScript.

## Как проверить

1. Откройте `performance-audit-report.md` и экспортируйте его в PDF через редактор Markdown или браузер.
2. Откройте `optimized-demo.html` в браузере и проверьте код оптимизации.
3. При реальной сдаче приложите PDF-отчёт и, если нужно, ссылку на этот репозиторий.
